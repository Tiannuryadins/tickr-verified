The gap this closes

TICKR paper-trades Coinbase tokenized stocks and logs every decision — plus a keccak256 hash of its reasoning — to a public journal on Base Sepolia. But that journal is unauthenticated: anyone can log entries, and nothing proves which agent made a decision or that a verified human stands behind it.

Concordium fixes exactly that. TICKR is registered in the CIS-8004 Agent Registry with a Verified by Concordium badge, its Base key is bound via CIS-8, and every decision is anchored in an on-chain accountability log — so anyone can verify: decision → reason hash → Concordium log entry → verified badge → Agent Card.

  • Decision + reasoning text
  • keccak256(reasoning) = reason hash
  • Record at tickr.log.<seq> on the agent token
  • Badge: owner + Active + card SHA-256 == on-chain hash

How to verify an entry (no key needed)
  1. Re-run the agent on the same inputs and recompute keccak256(reasoning text) — it must equal the record's h.
  2. Read tickr.log.<seq> from the agent token (get_metadata MCP tool) — the record must be there.
  3. Resolve the badge (section 1): owner + Active + card hash match.

3 · Agent Card

The ERC-8004 / A2A Agent Card. Its exact served bytes are hashed (SHA-256) and pinned on-chain as the agent's metadata_hash. This copy is pre-registration, so the badge extension carries "tokenAddress": null — never a fake badge. After registration the card is rebuilt with the real badge and re-pinned.
